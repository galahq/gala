# Phase 2 Plan 01: Public and Utility Route Stabilization

## Goal

Stabilize the public/utility route group from `config/routes.rb` and harden server-rendered Blueprint markup against the Blueprint 4 namespace migration.

## Tasks

1. Add explicit `.bp4-*` class counterparts to Rails-rendered error-page Blueprint markup while retaining `.pt-*`.
2. Add request coverage for error routes, redirects, `/up`, and unauthenticated `/runtime/stats`.
3. Run targeted RSpec for public/utility routes.
4. Browser-smoke `/404`, `/500`, `/up`, and one redirect via `localhost:3000` or `host.docker.internal:3000` when using the containerized browser.
5. Record QA evidence in `02-QA-GATE.md` and update milestone state before committing.

## Risk Notes

- Do not touch the broader Blueprint namespace bridge in this phase unless an error/utility route proves it is still needed.
- Do not change redirect destinations; these are published legacy links.
- Do not weaken `/runtime/stats` authorization.
