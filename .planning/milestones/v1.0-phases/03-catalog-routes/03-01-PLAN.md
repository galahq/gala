# Phase 3 Plan 01: Catalog Route Stabilization

## Goal

Stabilize the catalog route group and its visible Blueprint migration points without changing data behavior.

## Tasks

1. Add static `bp4` counterparts to catalog-specific hand-written class names on visible buttons, callouts, tags, dark wrappers, popovers, and submit controls.
2. Add request specs for catalog shell routes and JSON endpoints.
3. Run catalog-related Jest and RSpec gates.
4. Browser-smoke `/`, `/catalog/search`, `/catalog/libraries/sample`, `/catalog/languages`, `/tags`, and `/search` as practical.
5. Record QA evidence and commit before moving to Phase 4.

## Risk Notes

- Do not change endpoint schemas for catalog JSON consumers.
- Do not treat unauthenticated reader-specific JSON `401`s on the root page as catalog failure unless the visible page breaks.
- Do not change search query serialization except via tests if a regression is found.
