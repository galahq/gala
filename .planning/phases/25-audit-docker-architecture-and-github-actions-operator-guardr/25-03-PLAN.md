# Plan 25-03: One-Page Operator Manpages and Static Validation

<objective>
Write the CODEOWNER-facing operator manual as terse manpage-style pages and add lightweight validation so future edits keep the workflow docs complete, concise, and covered by owners.
</objective>

<threat_model>
- Long runbooks can hide critical side effects or recovery limits from operators under pressure.
- Docs that omit dry-run, side effects, verification, or rollback can encourage unsafe manual operation.
- Operator docs can drift from workflow names, inputs, and modes if validation does not check the required sections.
- Missing CODEOWNERS coverage can allow workflow or operator-doc changes to merge without the required owners.
</threat_model>
