# Plan 01: Production Deployment to AWS (no mutation of `www.learngala.com`)

## Objective

Create an explicit, safe, and reversible production-deployment package for AWS that:

- loads a `db/**/*` data dump as the deployment seed path,
- builds and pushes Docker images to ECR,
- syncs static assets to a production asset bucket target,
- keeps existing Heroku production untouched,
- uses ECS rollback via immutable tags / task definitions,
- and sets ALB as the BASE_URL source for this production deployment context.

## Constraint policy

- Do not issue destructive Heroku actions (deploys, restarts, config changes, releases).
- Heroku CLI calls are allowed only for safe reads and must be gated by explicit confirmation.
- Do not modify existing `www.learngala.com` Heroku resources.
- Do not write to or modify current production media/asset buckets unless import is explicitly requested.
- Keep secrets in AWS Secrets Manager; no plaintext secrets in repo files.
- Start with no custom VPC in this plan and use AWS default networking defaults where SST supports it.

    Create `scripts/deploy-gala-aws-production.sh` with the following behaviors:

1. Resolve environment and defaults:
   - AWS region defaults to `us-west-2`.
   - image repo defaults to `gala` in ECR.
   - default asset target bucket `gala-static-assets`.
   - dump source resolution from `db/**/*` with `.dump` and `.sql` support.

2. Build and push flow:
   - build Docker image from repo Dockerfile with production build args,
   - tag by `git sha`, `latest`, and optional deploy timestamp,
   - push tags to ECR.

3. Asset sync flow:
   - run asset precompile if needed,
   - sync JS/CSS/typography static assets to S3,
   - sync into target bucket with explicit cache-control settings.

4. Bucket migration behavior:
   - if explicit import path is enabled and source bucket is readable, sync source -> target.
   - never modify Heroku config or existing app routing directly.

5. Heroku secret fallback:
   - optionally read required SMTP and application values through read-only `heroku config:get` only,
   - if unavailable, emit placeholder markers and continue with a warning.
  </action>
