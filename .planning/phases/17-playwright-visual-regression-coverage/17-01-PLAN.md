<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → Rails app | HTML routes and session cookies are loaded from `localhost:3000`, including authenticated routes. |
| Test harness → local filesystem | Screenshot, report, and trace artifacts are written to local directories only. |
| Test harness → network | Browser page requests and third-party assets can emit noise; unknown failures are blocked by default. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|---|---|---|---|---|
| T-17-01 | S | `tests/visual/*` | mitigate | Enforce allowlist + fail on unknown console/network noise; require explicit summary updates before route acceptance. |
| T-17-02 | R | `playwright.config.mjs` | mitigate | Keep all artifact paths local (`tests/visual/__screenshots__`, `test-results`, `playwright-report`); avoid any storage client calls. |
| T-17-03 | I | `tests/visual/visual-route-helpers.mjs` | mitigate | Authenticate and logout per route to reduce session reuse and state leakage between snapshots. |
| T-17-04 | T | `playwright.config.mjs` + CLI command | mitigate | Separate compare and update scripts (`test:visual` vs `test:visual:update`) so baseline churn is explicit. |
</threat_model>
