<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local/CI deploy identity -> AWS staging | SST commands can create or remove AWS resources. |
| Internet -> staging ALB | Public requests reach the staging web service. |
| Planning docs -> secrets | Results may reference secret names but must not expose values. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Elevation of privilege | deploy commands | mitigate | Use only `--stage staging`; preserve production removal refusal and do not run production removal commands. |
| T-02-02 | Information disclosure | validation artifacts | mitigate | Record secret names/status only; never record values or generated database/Redis URLs. |
| T-02-03 | Spoofing | staging domain | mitigate | Validate the expected `staging.learngala.com` endpoint and SST outputs before treating responses as authoritative. |
</threat_model>
