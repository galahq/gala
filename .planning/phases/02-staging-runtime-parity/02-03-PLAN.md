<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Staging app -> S3 media bucket | Active Storage writes and deletes objects. |
| Staging app/worker -> SES | App can send email to external recipients. |
| SST task runner -> database/search/mail | Tasks can mutate schema, search index, and outbound mail behavior. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | Tampering | S3 media | mitigate | Decide staging bucket/prefix boundary before writes; use disposable staging objects. |
| T-02-08 | Information disclosure | mail validation | mitigate | Use controlled recipients and do not record SMTP credentials or message-sensitive data. |
| T-02-09 | Denial of service | scheduled tasks/search | mitigate | Run low-risk task invocations; avoid duplicate production-like schedule overlap. |
| T-02-10 | Tampering | database migration/search tests | mitigate | Use staging only and record any content mutation required for search freshness. |
</threat_model>
