<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Staging web/worker -> Redis/Valkey | App processes use generated Redis credentials for jobs, cache, Cable, and throttling. |
| Browser/client -> ALB WebSocket | WebSocket upgrade reaches Rails Action Cable. |
| Validation commands -> staging data | Test jobs and cache probes may mutate staging data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Denial of service | Sidekiq/Redis validation | mitigate | Use low-volume probes and avoid load testing in staging. |
| T-02-05 | Tampering | staging data/jobs | mitigate | Use staging-safe records/jobs only and document any mutation. |
| T-02-06 | Information disclosure | logs/results | mitigate | Do not record Redis URLs, database URLs, session cookies, or auth tokens. |
</threat_model>
