# Plan 20-01: Execute AWS Production Deployment in Safe Mode

## Objective

Execute a non-disruptive AWS production deployment path that:

- keeps `msc-gala` available for ActiveStorage unless a new media bucket is explicitly configured,
- stores compiled assets in `gala-static-assets`,
- hydrates required runtime secrets from Heroku into AWS Secrets Manager,
- restores database from `db/sqldump/seed.dump` when requested,
- and keeps deployment rollbacks fast via ECS image/task-definition history.

## Execution tasks

1. **Run deployment script with explicit deployment defaults**
   - `AWS_PROFILE=gala`
   - `AWS_REGION=us-west-2`
   - `HEROKU_APP_NAME=msc-gala`
   - `AWS_SECRET_PREFIX=gala/production`
   - `--asset-bucket gala-static-assets --source-bucket msc-gala`
   - `--create-asset-bucket`
   - `--seed-database`
   - `--database-url` provided

2. **Bucket policy and separation check**
   - ActiveStorage default path uses source media bucket without delete.
   - Static assets use compiled asset bucket.
   - Optional media bucket switch uses `--target-media-bucket` and one-way copy if needed.

3. **Secret hydration task**
   - Pull required keys from Heroku via read-only `heroku config:get`.
   - Write/update secrets at `gala/production/<KEY>` in Secrets Manager.

4. **Database seed task**
   - Use default `db/sqldump/seed.dump` unless overridden by `--data-dump`.
   - Support `.dump` restore and SQL-script restore.

5. **CloudFront rollout task**
   - Add/confirm distributions for:
     - `gala-static-assets`.
     - ActiveStorage media bucket (`msc-gala` or `TARGET_MEDIA_BUCKET`).

6. **Deployment validation and rollback**
   - Verify `/up` returns HTTP 200.
   - Verify one app route loads via ALB DNS.
   - Verify no destructive Heroku actions in command logs.
   - Verify rollback path to previous image tag works before increasing traffic.

## Acceptance criteria

- Deployment script can run in dry-run mode with all commands enumerated but no side effects.
- New deployment run has successful image push, asset sync, secret sync, and optional seed completion.
- Rollback to previous ECS task definition/image is documented and proven.
