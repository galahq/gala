# Plan 29-01: Build AWS spend inventory and pricing evidence

<objective>
Create the evidence base for `SPEND.md`: reconcile tracked SST infrastructure,
live AWS resources, and current official pricing sources into a safe,
repeatable inventory.
</objective>

<threat_model>
- T-29-01: Secret leakage through AWS command output. Mitigation: use targeted
  `--query` projections and never print SSM parameter values, env secrets, or
  connection URLs.
- T-29-02: Accidental production mutation during spend discovery. Mitigation:
  only run read-only AWS CLI commands and do not run SST deploy/refresh/import.
- T-29-03: False precision from stale pricing. Mitigation: cite current
  official AWS pricing pages/API and label estimates with date and assumptions.
</threat_model>
