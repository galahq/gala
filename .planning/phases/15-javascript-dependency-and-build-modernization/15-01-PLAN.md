# Plan 01: Conservative JavaScript dependency modernization (safety-first batch)

## Objective

Modernize compatibility-safe JavaScript dependency surfaces in small batches so v1.1 remains on:
- React 16.x
- BlueprintJS 4.x
- Shakapacker/Webpack production baseline
- Blueprint namespace compatibility and packed asset loading behavior

## Execution Context

- Keep phase-constrained hold decisions from `AGENTS.md` and phase context.
- Re-check package metadata in the current networked environment before each batch because registry checks in this run were previously blocked by offline conditions.
- Any change that alters production bundling or manifest behavior requires `localhost:3000` route QA with browser console and network checks.
