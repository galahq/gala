## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Rails app to Vite dev server | Backend-rendered pages may request assets from a separate dev server during experiments. |
| Temporary tooling config to production asset helpers | Spike configs can accidentally drift into committed production helper behavior. |
| Bundler CSS output to browser cascade | Vite or Vitest transforms may alter CSS order or duplicate Blueprint package CSS. |
| Package registry to local toolchain | Temporary spike dependencies are installed from npm through pnpm. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Spoofing | Vite dev server CORS/origin | mitigate | Keep any Vite server CORS setting limited to `http://localhost:3000`; do not open wildcard origins in committed config. |
| T-12-02 | Tampering | Rails production asset helper behavior | mitigate | Do not edit Rails layout helpers, Shakapacker config, Webpack config, or production pack tags unless VITE-05 evidence is strong and route QA is completed. |
| T-12-03 | Repudiation | Feasibility decision evidence | mitigate | Record exact commands, exit statuses, and relevant output lines in `12-01-SUMMARY.md` for each decision. |
| T-12-04 | Information Disclosure | Build and test logs | accept | Commands run locally and should not print secrets; do not paste `.env` contents or credentials into the summary. |
| T-12-05 | Denial of Service | Temporary dependency/config churn | mitigate | Use only bounded dev dependencies and temporary configs under `.planning/phases/12-vitest-and-vite-feasibility/spikes`; preserve existing pnpm install and Jest baseline commands. |
| T-12-06 | Elevation of Privilege | Temporary config scope | mitigate | Keep spike configs outside runtime Rails paths and avoid committed production helper replacement unless the explicit VITE-05 gate is met. |
| T-12-07 | Tampering | CSS/order regressions | mitigate | Inspect Vite manifest CSS output and preserve Sprockets ownership of Blueprint package CSS unless the summary records deliberate evidence for a different production path. |
