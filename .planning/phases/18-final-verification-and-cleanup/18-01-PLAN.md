# Plan 01: Identify and remove extraneous code safely

## Objective

Find and remove clearly extraneous code, compatibility leftovers, and dead assets while preserving route behavior and visible functionality.

## Execution Context

- Primary cleanup target is code with high confidence of non-use: deprecated frontend modules, stale legacy typing/config references, and obsolete helper paths.
- Every removal must be reversible via git and tested by scope before moving to the next candidate.
- Production-facing cleanup only when explicit import/reference checks and minimal QA gates are complete.
