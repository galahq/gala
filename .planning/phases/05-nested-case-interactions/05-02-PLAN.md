# Phase 05 Plan 02: Stats and Map Route Stabilization

<objective>
Stabilize `/cases/:case_slug/stats`, stats JSON/CSV/overview behavior, and the stats React map/date/table UI while preserving accepted local Mapbox production-style noise as non-blocking only when visible stats behavior remains usable.
</objective>

<must_haves>
## Truths

- D-06: After visible content surfaces, inspect stats/map before quiz and Wikidata/SPARQL.
- D-07: Protected stats browser checks require `/readers/sign_in` then clicking `a.oauth-icon-google`.
- D-10: Known stats overview HTML replacement and Mapbox local style noise are documented unless blocking route QA.
- D-13: Stats visual gates require nonblank overview, date controls, loading/error states, country table, and map container.
- D-14: Existing React 16 warnings, accepted local Mapbox production-style 404s, and third-party/browser noise are classified rather than failed unless visible behavior breaks.
- D-15: Deeper interaction checks are required for stats date/map controls.
- D-16: Preserve old Gala/Blueprint 2-era density and behavior; no redesign to Blueprint 4 defaults.

## UI Contract

- `/cases/:slug/stats` must render overview, date controls, loading/error states, country table, and map container.
- Local production-style Mapbox failures are accepted only if controls and fallback content remain usable.
- Existing stats map colors from `app/javascript/stats/map/mapColors.js` remain the map bin palette.
</must_haves>

<threat_model>
## Threat Model

| ID | Severity | Threat | Mitigation in Plan |
|----|----------|--------|--------------------|
| T-05-05 | medium | Stats route could expose protected analytics or pass unauthenticated redirects without admin visual QA. | Browser QA must use mock admin login and controller specs must preserve `stats?` authorization behavior. |
| T-05-06 | medium | Mapbox style/network failures could hide a blank stats UI. | QA must distinguish accepted style/network noise from blank map/container/date/table behavior. |
| T-05-07 | low | Stats overview raw HTML refresh could regress visible layout. | Inspect overview refresh behavior and document raw HTML replacement as non-blocking risk unless visible route breakage occurs. |
| T-05-08 | low | Date/filter changes could break URL or cache behavior. | Run existing stats Jest and RSpec suites before sign-off. |
</threat_model>
