Revised design: two speeds, existing states

Keep the deployed dev and production state identities. Separate rare platform changes from routine image-and-assets releases.

Stable path · explicit infrastructure mode

Owns: VPC, RDS, Redis, cluster, ALB, router, static CDN, secrets, schedules.

Runs: only infra:diff / reviewed infra:apply.

State: existing gala/dev and gala/production; no ownership transfer.

Config: database class, storage, scaling, and capacity are one-line stage values.

Rapid path · normal release

Owns: immutable image digest, immutable asset prefix, ECS task revisions.

Runs: build → upload → register tasks → update services → health check.

Does not run: sst deploy, resource refresh, CloudFront mutation, or database resize.

Rollback: restore the saved web/worker task revisions containing both image and asset references.

The channel pointer moves only after ECS is healthy. Failed builds may leave unreferenced immutable artifacts, but never a false “latest” release.

Human-friendly ECR tags

release-RUN-SHA — permanent release identity.

dev / pr-790 — healthy channel aliases.

production — digest currently deployed to production.

production-previous — immediate rollback candidate.

Aliases are moved server-side after health; ECS always pins the digest.

Static assets without invalidation races

Upload once under a release-specific prefix before starting ECS.

Keep the static-assets CloudFront distribution and immutable cache headers.

Never overwrite compiled files and never invalidate immutable paths.

Promotion reuses the exact dev-tested prefix; rollback restores the old prefix through the old task revision.

Low-risk migration order

1. Inventory and back up state; encode actual deployed values (production RDS is currently 20 GB, despite source saying 50 GB).

2. Mechanical module extraction with identical logical names and an exact no-op diff.

3. Make ECS-only release mode the default and advance manifests/tags only after health.

4. Create real pr-NNN runtime stages that reference dev foundation; migrate previews one at a time.

5. In a dedicated reviewed diff, remove only verified-unused app cache distributions/rules. Keep router and static CDN.
