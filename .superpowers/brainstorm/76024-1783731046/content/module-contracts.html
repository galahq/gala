Dependency contract

SharedRefs: router ID, bucket names, SES identity.

FoundationRefs: VPC ID, cluster ARN, database ID, Redis ID, secret prefix.

ReleaseSpec: immutable image digest, asset prefix, commit, host, slot.

RuntimeOutputs: service/task identifiers, target URL, health URL.

Contracts publish identifiers only—never secret values.

Enforced code rules

Only core/context.ts reads process.env.

No resource construction at module import time.

Stage modules compose builders but cannot modify builder internals.

Preview imports references—not createFoundation.

Every builder returns a small typed output contract.

Cross-stage discovery

Durable stages publish non-secret IDs under deterministic SSM contract names. Derived stages read those IDs and call SST static get methods. This avoids scraping CLI output or duplicating ownership.
