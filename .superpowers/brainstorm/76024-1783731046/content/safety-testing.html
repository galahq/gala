Hard stop conditions

Any preview operation addressing another PR stage.

Any S3, SES, database, cache, VPC, or shared-router replacement.

Any destroy or ownership transfer of an adopted Heroku resource.

Any production route change outside promote/rollback.

Any apply whose plan identity differs from the reviewed artifact.

Stage-specific allowlists

pr-NNN: own runtime, jobs, release prefix, exact PR route.

dev: dev runtime by default; foundation only in scoped infra mode.

production slot: inactive runtime only; no root pointer.

production: pointer and explicitly scoped durable infra.

shared: local bootstrap/reconciliation only; never routine CI.

Cron ownership switches once, using a promotion lease. Rollback restores the route and active worker/cron designation; destructive contract migrations wait until the rollback window closes.

Local access safety

sst dev --stage local-NAME references dev networking and starts the SST tunnel.

A generated, short-lived Compose env file exposes the database host through the tunnel.

Default database role is non-owner and non-destructive; explicit elevation is separate and time-limited.

Local stages own no durable AWS resources.

Verification ladder

Unit: classifier, ownership, contracts, diff policy.

Fixture: known-good and known-dangerous SST diffs.

CI: compile, workflow contracts, docs consistency.

Cloud plan: manual, non-refreshing, artifacted.

Post-apply: service health, route target, no unrelated changes.
